Executive Summary

What it is and why it matters

AI QA Portal (TIP) is a test intelligence platform that transforms how QA teams build and maintain automated tests for Salesforce. Instead of writing Robot Framework scripts manually, testers describe what they want to test in plain English — the AI generates, validates, and executes the automation script automatically.

The platform connects to live Salesforce sandbox environments, understands org-specific layouts and picklist values, and produces production-ready test suites that handle field validation, self-healing locators, and cross-org compatibility out of the box. Version 3.1 ships the next-generation React + Next.js frontend (deployed to Vercel) backed by a containerised FastAPI REST backend (65+ endpoints across 12 routers), with a structured user-story → test-case workflow and the foundation for Google Workspace SSO and per-user data isolation.

Key value proposition: Reduce test script creation from hours to minutes. Eliminate the need for Robot Framework expertise. Enable any QA engineer to produce enterprise-grade Salesforce test automation through natural language.

Problem Statement

Challenges in Salesforce QA today

⏱

Slow Script Creation

Writing Robot Framework scripts for Salesforce requires deep knowledge of SLDS DOM structure, Lightning locators, and picklist handling. A single CRUD test can take 2-4 hours to build manually.

🛠

High Maintenance Cost

Salesforce releases (3x per year) change DOM structure, breaking locators silently. Teams spend more time fixing scripts than writing new ones.

👥

Skill Barrier

Only engineers with Robot Framework + Selenium + Salesforce expertise can contribute to automation. Business analysts and manual testers are excluded from the process.

📈

Org Variability

Each Salesforce org has unique page layouts, required fields, picklist values, and record types. Scripts built for one org break when run against another.

Solution Overview

How AI QA Portal solves these challenges

The platform introduces an AI-driven workflow where testers interact with a conversational agent panel (similar to Cursor or ChatGPT) to describe test scenarios. The AI understands Salesforce-specific context — object types, field labels, picklist behavior, address fields, app names — and generates syntactically correct, org-aware Robot Framework scripts.

Key Features

Platform capabilities at a glance

🤖

AI Test Generation

Two modes: MCP Stepwise (verified step-by-step against keyword catalog) and Quick Generate (fast single-shot LLM call). Both produce complete .robot suites.

🌐

Multi-LLM Support

Switch between Gemini, GPT-4, Claude, and Cohere via the Settings page. API keys managed through environment variables or session overrides.

🛠

Self-Healing Keywords

Smart keywords handle real-world complexity: State/Province abbreviation mapping (CA→California), post-login phone prompt dismissal, field fallbacks for org layout variations.

📁

Project Workspaces

Organize tests by project with multi-environment (Dev/QA/UAT/Prod) and multi-persona (System Admin, Marketing User) credential management.

⚡

Parallel Execution

Run full test suites with Pabot (parallel Robot Framework). Auto-retry flaky tests and merge results before reporting.

🔍

Live Org Inspector

Connects to the Salesforce org via API to discover actual picklist values, required fields, and field types — injecting real data into the generation prompt.

📖

User Stories → Test Cases

Capture acceptance criteria as versioned user stories. AI generates candidate test cases for review and batch-approval. Approved cases run as Robot suites with one click and stale automatically when the underlying story changes.

🚀

API Data Seeding

Instant prerequisite data creation via Salesforce REST API (simple-salesforce). Tests that need existing records seed them in setup, not through slow UI navigation.

🧹

Post-Processing Pipeline

Automated fixes for AI-generated code: Test Setup placement, credential stripping, CSV variable injection, hallucinated keyword removal, and format validation.

📊

Analytics Dashboard

Per-project run history, pass/fail trends, and execution metrics. Visual reporting with drill-down into individual test results.

💬

Natural Language Understanding

Interprets conversational prompts correctly: "Company should be Acme" extracts "Acme" (not "should be Acme"). Handles abbreviations, typos, and informal phrasing.

💡

AI Agent Panel

Cursor-style right-side panel for prompt input, quick-start templates, and generation controls. Status updates stream in the main content area during script creation.

🎯

Smart State/Province Mapping

Automatically converts abbreviations (CA, TX, NY) to full names (California, Texas, New York). Handles both dropdown and text-input field variants across orgs.

🔒

Post-Login Prompt Handling

Automatically dismisses Salesforce phone registration, email verification, and "Remind Me Later" prompts after login — no manual intervention needed.

🧠

NLP Prompt Interpretation

Strips conversational filler ("should be", "set to", "use") from field values. "Company should be Acme" correctly extracts "Acme", not "should be Acme".

🔧

Auto-Fix Post-Processor

5-stage pipeline fixes common AI mistakes: Test Setup placement, credential leaks, hallucinated variables, CSV injection, and robotidy formatting.

🎨

Next-Gen Futuristic UI

React + Next.js frontend with Three.js 3D particle backgrounds, Framer Motion animations, glassmorphism cards, and neon gradient theme. Standalone SPA at port 3000.

🔌

FastAPI REST Backend

65+ REST endpoints across 12 routers. Full programmatic access to generation, execution, projects, user stories, runs, analytics, and MCP. Swagger docs at /docs.

☁

Cloud Deployment

Frontend ships to Vercel with auto-deploy from GitHub main. Backend runs as a Docker image (Python + Robot + Chromium) reachable through a Cloudflare tunnel today, with Fly.io Machines + Volumes as the production target.

🔒

Workspace SSO & RBAC (in progress)

Google Workspace login restricted to a single domain (e.g. @astounddigital.com). Per-user data isolation, project memberships, and Admin / Project Manager / Team Lead / Team Member roles are landing in phased releases.

FastAPI Backend (v3.1): All platform functionality is accessible via 65+ REST endpoints across 12 routers: projects, generate, runs, user-stories, test-cases, tags, llm, mcp, salesforce, catalog, analytics, personas, orgs, locators. Every protected route enforces a session JWT signed by the frontend's NextAuth instance. Interactive API docs at /docs (Swagger) and /redoc.

The AI Bridge sends user prompts along with the keyword catalog (900+ keywords) and the system prompt (600+ lines of Salesforce-specific rules including NLP interpretation, address field handling, and no-delete policy) to the selected LLM. The response goes through a 5-stage post-processing pipeline: credential stripping, LLM garbage removal, CSV variable sanitization, Test Setup/Teardown placement fix, and robotidy formatting — before presenting the script for human review.
